# Protótipos do Sistema de Alertas Comunitários

Arquivo editável: Alertas_Comunitarios_Astryx.figcraft, na pasta principal do pacote.

## Apresentação no FigCraft

1. Abra o arquivo `.figcraft`.
2. Selecione o quadro `RFxxx_A` do requisito que deseja apresentar e inicie a apresentação do protótipo. Há um início de fluxo para cada um dos 13 requisitos.
3. Clique no botão principal para seguir à segunda tela. Os menus laterais com links levam aos demais fluxos.

Cada requisito possui duas imagens PNG, também inseridas no documento. A e B são as duas telas principais, não uma especificação de todos os estados possíveis.

| Requisito | Tela A | Tela B |
|---|---|---|
| RF001 | Cadastro de morador | Consulta do cadastro |
| RF002 | Dados da residência | Consulta de residências |
| RF003 | Consulta de áreas de risco | Edição da área |
| RF004 | Consulta de representantes | Cadastro de representante |
| RF005 | Entrada de morador e representante | Criação de nova senha no primeiro acesso |
| RF006 | Registro de ocorrência | Confirmação com protocolo |
| RF007 | Solicitação do código | Código e redefinição da senha |

## Alcance do protótipo

As telas e seus textos são editáveis. A navegação demonstra os caminhos principais; campos e botões secundários ilustram a interface. Não há envio real de SMS/WhatsApp, autenticação, processamento de fotos, banco de dados ou validação funcional. Nomes, endereços, números e datas nas telas são exemplos fictícios.

As telas móveis representam o acesso ao sistema web pelo celular; não indicam aplicativo nativo. As telas de trabalho representam o acesso pelo computador.

Referência visual: Astryx Neutral, da Meta, com Figtree, cores neutras, contraste, hierarquia de texto e ações principais destacadas. Trata-se de uma adaptação visual em camadas nativas do FigCraft, não da execução dos componentes React do Astryx. Fontes: https://github.com/meta/astryx e https://astryx.atmeta.com/docs/tokens.

A memória de pontos de função é fornecida em arquivo separado. O total de 203 PF é uma estimativa acadêmica não ajustada, com premissas explícitas, sujeita à revisão do professor.
