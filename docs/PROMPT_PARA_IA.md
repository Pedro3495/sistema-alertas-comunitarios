# Prompt para começar uma tarefa

Copie e preencha antes de iniciar uma execução:

```text
Trabalhe neste repositório e siga AGENTS.md.
Tarefa/issue: [link ou ID]
Requisito: [RFxxx]
Spec: specs/RFxxx.md
Minha branch: [feat/...]
Responsável humano: [nome]
Revisor humano: [nome do colega]
Escopo deste PR: [parte exata do requisito]
Arquivos/contratos combinados: [lista]

Primeiro leia as fontes, confira branch e git status e mostre um plano curto.
Implemente apenas esse escopo, em passos pequenos que eu consiga explicar.
Não invente regras nem altere o documento aprovado.
Antes de editar contratos compartilhados ou criar migração, coordene comigo.
Execute as verificações relevantes. Ao terminar, informe mudanças, testes
realmente executados, decisões de POO e pendências. Não faça merge.
```

Não envie senhas, CPF/telefone reais, `.env` ou banco da aplicação no prompt. Dados dos protótipos são fictícios. Leia o código produzido antes de aprovar.
